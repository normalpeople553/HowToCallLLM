## 这是什么

国内能叫得上名字的大模型厂商有十几家，每家都有自己的平台、文档、模型名和计费规则。新手一上来就懵：**到底用哪家？key 去哪领？代码怎么写？会不会一不小心扣很多钱？**

这份指南不做官方文档的搬运工。它只回答新手真正关心的几件事：

- 🔰 **怎么从零跑通第一次调用**（5 分钟，不用懂任何术语）
- 🎯 **怎么用一套代码切换所有厂商**（核心：OpenAI 兼容）
- 💰 **免费额度怎么薅、各家多少钱、新手第一家选谁**
- 🧯 **报错了怎么办、有哪些坑**

作者的主张很简单：**调用大模型这件事，90% 的厂商是同一个套路，没必要学十几遍。** 你只需要学会一个"万能模板"，再记住每家"改哪两行"就够了。

## 一个最重要的事实

**国产大模型几乎全都兼容 OpenAI 的接口格式。**

所以下面这段代码，改两行就能换成 DeepSeek、Kimi、智谱、通义……：

```python
from openai import OpenAI

client = OpenAI(
    api_key="你的key",
    base_url="https://api.deepseek.com",   # ① 改这一行：换厂商
)
resp = client.chat.completions.create(
    model="deepseek-v4-flash",             # ② 改这一行：换模型
    messages=[{"role": "user", "content": "你好"}],
)
print(resp.choices[0].message.content)
```

详见 [book/02-一个套路调遍所有模型.md](book/02-一个套路调遍所有模型.md)。

## 信息可信度与时效

模型名、价格、免费额度变得非常快（DeepSeek 的旧模型名 2026 年就弃用过一轮）。为了不误导你，本指南：

- 每个事实都标注来源类型，并在厂商页顶部写明**最后核对日期**；
- 价格、模型名一律以「官方文档链接 + 核对日期」为准，不凭记忆写；
- 代码标记是否真实跑通过。

标记含义：

| 标记 | 含义 |
|---|---|
| ✅ **已实测** | 作者用真实 key 跑通过（截至核对日期） |
| 📄 **官方文档** | 内容来自厂商官方文档，附链接，但可能随版本更新失效 |
| 💬 **社区经验** | 来自开发者社区/个人经验，参考即可 |
| ⚠️ **易变** | 价格、模型名、免费额度等随时可能变动，用前请点官方链接复核 |

> 本指南最近一次信息核对：**2026-10-13**。如果你发现某条信息过期了，欢迎提 Issue。
