## 从这里开始

| 入口 | 你能找到什么 |
|---|---|
| [人类篇](human/README.md) | 快速上手、完整代码讲解、检查 Agent 实现、通用参数与踩坑 |
| [模型目录](models/README.md) | 按厂商和准确型号查说明书、参数、示例、官方价格与调用代码 |
| [Agent 篇](agents/README.md) | 接入规范、资料查询、代码生成、迁移与排错 |

人类篇和 Agent 篇共用官方型号卡片和调用代码，中英文也共用同一套源码。实测记录只留本地，不随仓库发布。

## 直接交给 Agent

把仓库地址和下面这段任务一起交给编程 Agent；这是项目建议，不是模型调用代码。具体接入规则见 [Agent 篇](agents/README.md)。

> 参考 https://github.com/normalpeople553/HowToCallLLM ，在我的当前项目接入 DeepSeek 的普通文本调用。从仓库 Agent 篇开始，按路由确定付费默认型号，优先复用完整示例并保留响应检查。告诉我环境变量名、安装和运行命令，先做离线检查；真实调用等我明确授权。不要回显密钥，不要把测试过程上传。

已有项目保留现有语言和依赖管理方式；没有项目时按 Agent 规范确定语言。示例和生成器的结果不能代替改写后代码的验证。

## 维护与复现

[调用代码目录](docs/示例实测状态.md) · [验证与复现](docs/验证与复现.md) · [来源规则](docs/来源与核验规则.md) · [翻译检查](scripts/check_translations.py)

项目默认调用和维护示例使用付费型号，不因报错静默回退免费型号。价格直接查模型目录中的官方页面；已有实测不代表 Agent 改写或任意参数组合已通过。详细边界见来源规则。

Key 只放环境变量或被 Git 忽略的 .env，不写入代码、聊天、报告或提交，不用模板覆盖已有 .env。[忽略配置](.gitignore) · [安全与来源规则](docs/来源与核验规则.md)

安装与检查命令统一见验证与复现；[CI 模板](ci/offline-checks.yml)尚未启用 GitHub Actions。
