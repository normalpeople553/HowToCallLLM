# Doubao · language-model list

[Model directory](../../../models/README.en.md) · [中文](../../../docs/model-lists/doubao.md)

Official documentation checked: 2026-10-14. [Official catalog](https://docs.volcengine.com/docs/ark/model-list?lang=zh) · [Source data](../../../data/model-lists/doubao.json)

Scope: mainland-China Ark pay-as-you-go API. Includes Doubao-owned Model IDs from the official catalog's text-generation section on the check date, including character, translation and multimodal-understanding language models. Retired versions are excluded; this list is not a historical archive. Excludes resold models, image/video/3D generation, standalone speech services, embeddings, rerankers, pure OCR and single-purpose intent classifiers. Coding/Agent Plan endpoints, short names and lifecycles require separate subscription documentation and are not interchangeable with pay-as-you-go API IDs. Past-model status, EOM and EOS are distinct; a price listing alone is not availability evidence. Region, account and console permissions still apply. This is an official-document inventory, not an API execution test; it contains no copied prices or request limits.

Availability is a dated official-document snapshot, not an account-level or live-call guarantee. Billing links do not imply API access; read each row's restrictions. Coverage joins exact IDs to public manuals, parameters and code, never private execution records or another alias/family's coverage.

Text output is the scope; modality labels describe input understanding, not image/audio generation. No entry here expands the snippet generator's supported models.
