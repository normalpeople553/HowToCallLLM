# Qwen · language-model list

[Model directory](../../../models/README.en.md) · [中文](../../../docs/model-lists/qwen.md)

Official documentation checked: 2026-10-14. [Official catalog](https://help.aliyun.com/zh/model-studio/models) · [Source data](../../../data/model-lists/qwen.json)

This list records exact Qwen-owned hosted language-model IDs explicitly present in Alibaba Cloud Model Studio's public catalog, model pages, and regional pricing tables. It covers current commercial mainlines, documented snapshots/aliases, multimodal understanding, coding, long-document, translation, deep-research, and currently identifiable hosted open-weight models. An entry supported only by pricing or historical release records is marked unknown when current availability is not established; a price is not proof that an ID remains callable. Regions, deployment scopes, account permissions, and protocol support differ. This is not an all-region inventory or an exhaustive list of historical/open-weight snapshots, fine-tunes, or dedicated-deployment IDs. Third-party resale, image/video generation, standalone ASR/TTS, realtime speech interfaces, embeddings, reranking, OCR-only models, and model routers are excluded. Omni models are included for multimodal understanding with text output. Trial credits do not make a model free. This documentation check sends no API requests, inherits no test result from another model or example, and changes no repository default.

Availability is a dated official-document snapshot, not an account-level or live-call guarantee. Billing links do not imply API access; read each row's restrictions. Coverage joins exact IDs to public manuals, parameters and code, never private execution records or another alias/family's coverage.

Text output is the scope; modality labels describe input understanding, not image/audio generation. No entry here expands the snippet generator's supported models.
