# MiniMax · language-model list

[Model directory](../../../models/README.en.md) · [中文](../../../docs/model-lists/minimax.md)

Official documentation checked: 2026-10-14. [Official catalog](https://platform.minimax.cn/docs/faq/models) · [Source data](../../../data/model-lists/minimax.json)

Checked against mainland-China MiniMax hosted-language API catalogs, calling guides, billing pages and retirement notices. Covers the listed M-series conversational, reasoning, coding and multimodal-understanding models; language models explicitly marked retired are excluded. This is not an exhaustive archive of earlier abab/Text-01 models removed from those catalogs; local open weights are not evidence of hosted API availability. Pay-as-you-go API, M Plan and Token Plan keys, billing and routing must be distinguished. Subscription-only preview access is noted per model; international-account or other-region permissions are not inferred. Excludes resold models, image/video/music generation, standalone speech, embeddings, reranking and pure OCR. No fixed prices, request limits or new execution tests are included. Lifecycle notices take precedence over stale entries in price tables.

Availability is a dated official-document snapshot, not an account-level or live-call guarantee. Billing links do not imply API access; read each row's restrictions. Coverage is joined by exact ID from maintained cards and current-source HTTP reports, not inherited through aliases or family names.

Text output is the scope; modality labels describe input understanding, not image/audio generation. No entry here expands the snippet generator's supported models.
