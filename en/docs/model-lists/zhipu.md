# Zhipu GLM · language-model list

[All vendors](README.md) · [中文](../../../docs/model-lists/zhipu.md)

Official documentation checked: 2026-10-14. [Official catalog](https://docs.bigmodel.cn/cn/guide/start/model-overview) · [Source data](../../../data/model-lists/zhipu.json)

Scope: BigModel's China-region standard hosted text, reasoning, coding and vision-language APIs. Available means listed in current official catalog/request enums, not live account access or successful testing. Only officially evidenced exact API IDs are recorded; display names do not generate IDs, and family parameters, capabilities or verification are not inherited. Coverage includes current major entries plus some exact still-listed older and routed IDs, excluding retired IDs; it is not a dynamic account-wide inventory; historical pricing alone does not establish availability. Free entries are catalog-only and do not change this repository's paid defaults/examples. Excludes image/video generation, speech/realtime audiovisual services, embeddings/reranking, OCR-only and private-deployment-only models. Modalities are limited by this schema to text/image/video; file containers and protocol details are not expanded. Display-only entries such as CodeGeeX-4, and other GLM-Z1 variants without separately confirmed hosted IDs, are not guessed. Prices are linked without numeric snapshots; region, entitlement and lifecycle remain subject to current official information.

Availability is a dated official-document snapshot, not an account-level or live-call guarantee. Billing links do not imply API access; read each row's restrictions. Coverage is joined by exact ID from maintained cards and current-source HTTP reports, not inherited through aliases or family names.

Text output is the scope; modality labels describe input understanding, not image/audio generation. No entry here expands the snippet generator's supported models.
