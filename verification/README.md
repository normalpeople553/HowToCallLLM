# 本地验证说明

[English](README.en.md)

公开仓库只保留说明书、官方出处、调用代码和检查工具，不发布实测 JSON、回复、思考正文、HTTP 记录、用量统计或源码校验哈希。[发布规则](../docs/来源与核验规则.md)

维护者的原始记录存放在被 Git 忽略的 `.local/evidence/`。它们不随克隆或下载提供；没有这些记录的读者仍可阅读、检索与执行离线检查，不能因此宣称私有测试通过。源码变更后仍须重新检查相应调用，不修改旧哈希补成成功。

真实调用须获用户授权，可能计费或上传素材；执行器默认只列代码清单，显式 `--execute` 才调用。新报告默认写入本地目录，不记录测试时间与耗时。安装、命令和退出码见[验证与复现](../docs/验证与复现.md)。

本次转存保留原始记录以供本地维护，不重写已经公开的 Git 历史。旧历史仍可能包含测试时间；当前目录隐藏不等于历史已清除。
