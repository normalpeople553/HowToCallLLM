# 豆包 · 语言模型清单

[全部厂商](README.md) · [English](../../en/docs/model-lists/doubao.md)

范围为中国内地火山方舟按量 API：收录核对日官方模型列表文本生成栏的豆包自研 Model ID，含角色、翻译及多模态理解语言模型；另收录当前下线公告中的既往对话、推理、编程和 GUI 语言版本以供迁移辨认，不宣称穷尽 2024/2025 历史档案。排除转售型号、图像/视频/3D 生成、独立语音服务、向量、重排、纯 OCR 和单一意图分类器。Coding/Agent Plan 的入口、短名称和生命周期须另查订阅文档，不与按量 API 混用。往期、EOM 与 EOS 分开判断，价目中出现不等于可用；实际权限以地域、账户及控制台为准。本表是官方资料核对而非 API 实测，不包含固定价格或调用参数上限。

可用性是有日期的官方文档快照，不保证你账户具备权限，也不表示本次实际调用。定价入口不等于接入权限，限制见逐行说明。仓库覆盖按准确 ID 关联维护卡片和当前源码 HTTP 报告，不按别名或系列继承。

本清单以语言输出为范围；模态表示输入理解，不是图像/音频生成能力。出现在这里不自动扩展代码生成器支持的型号。
