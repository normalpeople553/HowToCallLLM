# 00 · 欢迎使用模型说明书

《模型说明书》同时服务三类读者：新手按章节跑通调用，老手快速查参数，编程 Agent 从结构化目录生成或排查代码；项目目标与边界由 [`README.md`](../README.md)和 [`SKILL.md`](../skills/model-manual/SKILL.md)共同定义。

## 阅读路线

- 第一次调用：读 [01](01-5分钟跑通第一次调用.md) 和 [02](02-一个套路调遍所有模型.md)。
- 已经会调用：查 [厂商资料卡](03-厂商攻略/)与[官方价格入口](04-免费额度与省钱攻略.md)。
- 正在报错：先按 [05](05-新手必会与报错速查.md)保留原始错误并最小化复现，再查 [06 真实踩雷](06-真实踩雷与生产检查.md)中的思考 token、截断、JSON、工具循环、流式与限流问题。
- 让 Agent 工作：要求它先读 [`skills/model-manual/SKILL.md`](../skills/model-manual/SKILL.md)。

以上是本项目的阅读约定，不是厂商功能结论；约定的分类方式见[来源与核验规则](来源与核验规则.md)。

## 可信度标记

| 标记 | 本项目中的含义 |
|---|---|
| 官方 | 同段或同表格行附厂商官方链接 |
| 实测 | 附日期与 [`tests/verify_calls.py`](../tests/verify_calls.py) |
| 项目建议 | 编辑者的工作流、安全或选型建议 |
| 未知 | 暂无足够官方资料或仓库实测，不做推断 |

价格、额度、模型名和参数能力都可能变化；本项目将官方页面作为事实真源，并把机器可读链接集中在 [`vendors.json`](../skills/model-manual/references/vendors.json)。完整规则见[来源与核验规则](来源与核验规则.md)。

## 当前范围

仓库当前覆盖五家厂商的文本 Chat Completions、流式调用和目录中明确记录的思考开关；JSON Schema、Tool Calling、多模态、Embedding 和 Responses API 未记录时不做兼容性推断。[Skill 边界](../skills/model-manual/SKILL.md)

仓库示例要求 Python 3.9+，依赖版本以 [`requirements.txt`](../requirements.txt)为准；Key 安全规则见 [05](05-新手必会与报错速查.md#key-安全)。

开始：[01 · 5 分钟跑通第一次调用](01-5分钟跑通第一次调用.md)。
