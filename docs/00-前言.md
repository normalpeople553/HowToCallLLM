# 00 · 阅读说明

[English](../en/docs/introduction.md)

《模型说明书》分为[人类篇](../human/README.md)与[Agent 篇](../agents/README.md)：人类按问题了解使用方法、模型差异与实测边界，编程 Agent 按任务读取资料并完成代码工作。[README](../README.md)是共同总入口。两种入口共享型号卡片和原始报告，不分别维护两套模型事实；这是使用角色的区分，不是新手与老手的区分。[来源规则](来源与核验规则.md)

## Agent 怎么读

从[Agent 篇](../agents/README.md)进入 [`skills/model-manual/SKILL.md`](../skills/model-manual/SKILL.md)，定位任务与准确型号，再按需读取[任务流程](../skills/model-manual/references/workflows.md)中的接入、迁移、排错、未知型号或验证部分。

资料定位顺序：厂商目录 → 准确型号卡片 → 对应说明书和示例 → 相关验证报告。厂商目录只提供默认型号路由，不能把默认参数直接套给同厂商其他型号；工作流和路径规则见上述 Agent 入口。

## 人类怎么读

在[人类篇](../human/README.md)复制一条任务指令交给 Agent，或按自己要判断的问题查资料：

- 能力与限制：查[模型说明书](../models/README.md)及其官方来源。
- 调用差异与失败原因：查[统一调用套路](02-一个套路调遍所有模型.md)、[报错速查](05-新手必会与报错速查.md)和[真实踩雷](06-真实踩雷与生产检查.md)。
- 价格与额度：查[官方费用入口](04-免费额度与省钱攻略.md)。
- 实测是否覆盖自己的需求：查[验证状态](验证状态.md)与原始报告；自己复测时查[验证与复现](验证与复现.md)。

[第一次调用](01-5分钟跑通第一次调用.md)保留为手动运行的辅助教程，无需按章节顺序阅读。人类篇与 Agent 篇按使用角色划分，不按熟练程度拆分读者。

## 可信度标记

| 标记 | 本项目中的含义 |
|---|---|
| 官方 | 同段或同表格行附厂商官方链接 |
| 实测 | 附证据编号、测试范围、脱敏报告及对应脚本 |
| 项目建议 | 编辑者的工作流、安全或选型建议 |
| 未知 | 暂无足够官方资料或仓库实测，不做推断 |

“官方说明支持”与“一次请求通过”是两类证据。超时、限流或跳过不等于模型不支持；一次通过也不代表其他型号或所有业务任务都可靠。价格、额度、模型名和参数可能变化，具体证据与维护方式见[来源与核验规则](来源与核验规则.md)。

## 当前范围

仓库覆盖已收录型号的 Chat Completions、流式调用及卡片明确记录的思考开关；JSON、Tool Calling、多模态和其他 API 只按具体卡片记录使用，不推断完整 OpenAI API 兼容。[Skill 边界](../skills/model-manual/SKILL.md)

示例要求 Python 3.10+，独立复现使用 [`requirements-lock.txt`](../requirements-lock.txt)；实际安装与验证见[验证与复现](验证与复现.md)，Key 安全规则见[报错速查](05-新手必会与报错速查.md#key-安全)。
