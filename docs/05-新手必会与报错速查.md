## 一、报错速查表

| 报错关键词 | 原因 | 怎么办 |
|---|---|---|
| `401` / `Authentication Fails` / `Invalid token` | key 错了、没读到、或环境变量没生效 | 核对 key；`echo $DEEPSEEK_API_KEY`（换成你的变量名）看有没有值；别多留空格/引号问题 |
| `402` / `Insufficient Balance` / 欠费 | 账户没余额，或没用上赠送额度 | 去平台看余额与赠送额度；新手先充值 1～10 元或换免费模型 |
| `404` / `Model Not Exist` / `model not found` | 模型名写错、已下线、或该模型没开通 | 用[各厂商攻略](03-厂商攻略/)里实测过的名字；**豆包要先在开通管理里开通模型**；Kimi 别用 `moonshot-v1-*`；通义没有 `qwen3-flash` |
| 回答是空字符串 `''` | 思考模型的思考链吃光了 `max_tokens`（智谱免费模型实测会这样） | 调大 `max_tokens`（≥256），或加 `extra_body` 关思考，见 [02 章](02-一个套路调遍所有模型.md) |
| `429` / `Rate limit` / `Too Many Requests` | 触发免费/低配档的频率（RPM/TPM）限制 | 降低请求频率、加重试间隔；免费档本来就限流，重度用要付费提额 |
| `context length` / `maximum context` | 发的内容超过模型上下文上限 | 精简历史/换长上下文模型（如 Kimi 换 `kimi-k3` 1M） |
| `Connection error` / 超时 / `SSLError` | 网络或代理问题 | 国内五家**直连即可，关掉 VPN/代理**再试；检查公司网络/防火墙 |
| `PermissionDenied` / `119`（百炼类） | 没实名 / 没开通模型服务 / 地域不对 | 完成实名认证、控制台开通模型、检查地域与免费额度适用范围 |
| 流式片段为空（正常现象） | 流式协议里部分 chunk 没有内容 | 流式里用 `delta.content or ""` 兜底即可 |
| `KeyError: '环境变量名'`（示例代码） | 没 `export` 对应 key | 回看 [01 章第 4 步](01-5分钟跑通第一次调用.md) |

### 万能排查三步

1. **看报错里的 HTTP 状态码**：401 找 key、402 找钱、404 找模型名、429 找频率、连接错找网络。
2. **最小代码复现**：用 [`examples/01_quickstart.py`](../examples/01_quickstart.py) 这种最短例子跑，能跑通就是你业务代码的问题。
3. **打印 `resp.usage` 和原始异常**：确认扣了多少 token、异常完整信息是什么，别只看表面一句话。

## 二、常用进阶参数

```python
resp = client.chat.completions.create(
    model="deepseek-v4-flash",
    messages=messages,
    temperature=0.7,      # 0~2：小=稳定严谨，大=发散有创意
    max_tokens=500,       # 输出上限，省钱保险丝
    top_p=0.9,            # 与 temperature 类似的多样性旋钮，一般只调一个
    stream=False,         # True=打字机流式
)
```

- 做分类、抽取、代码这类**要稳定**的活：`temperature` 调低（0～0.3）；
- 写文案、起名、 brainstorm：可以调高（0.8～1.2）。

## 三、把回答变成程序能用的数据（JSON Mode）

想让模型返回结构化 JSON 而不是一段大白话，多数兼容模型支持 `response_format`（具体以各家文档为准）：

```python
resp = client.chat.completions.create(
    model="deepseek-v4-flash",
    messages=[{"role": "user", "content": "返回一个JSON，包含name和age两个字段，人物：小明26岁"}],
    response_format={"type": "json_object"},
)
print(resp.choices[0].message.content)     # 一段可被 json.loads 解析的字符串
```

> 提示词里最好明确要求"返回 JSON"，否则部分模型可能不遵守。需要更可靠的"函数调用"（Function/Tool Calling）时，DeepSeek、智谱、通义的较新型号大多支持，用法与 OpenAI 一致——这部分留待后续版本展开。

## 四、API Key 安全（新手最容易翻车）

- ❌ 不要把 key 写死在代码里、不要提交到 GitHub、不要发群/截图；
- ✅ 用环境变量或 `.env` 文件（仓库已配 [.gitignore](../.gitignore) 忽略 `.env`）；
- ✅ key 一旦疑似泄露，立刻去平台**删除并重新生成**；
- ✅ 给 key 设置用量上限/预警，别用一个主 key 走天下。

## 附录：把 API Key 永久配置好

每次开终端都 `export` 太麻烦，可写进 shell 配置文件：

```bash
# macOS / Linux：zsh（Mac 默认）写进 ~/.zshrc，bash 写进 ~/.bashrc
echo 'export DEEPSEEK_API_KEY="sk-你的key"' >> ~/.zshrc
source ~/.zshrc          # 立即生效
```

```powershell
# Windows PowerShell：永久写入用户环境变量
[System.Environment]::SetEnvironmentVariable("DEEPSEEK_API_KEY", "sk-你的key", "User")
```

配好后重开终端，`echo $DEEPSEEK_API_KEY` 能看到值就成功了。其他三家把变量名换成 `MOONSHOT_API_KEY` / `ZHIPU_API_KEY` / `DASHSCOPE_API_KEY` 即可。
