# 来源与核验规则

[English](../en/docs/evidence-policy.md)

以下是本仓库的编辑与发布规则；项目约定不伪装成厂商承诺。

## 公开什么

公开说明书、逐项参数解释、官方来源、可运行调用代码、锁定依赖及离线检查工具。实测 JSON、模型回复、思考正文、HTTP 请求记录、token 统计、源码校验哈希和测试时间不随仓库发布。已有实测资料只留维护者本地，见[本地验证说明](../verification/README.md)。

示例维护者需要真实运行准备发布的调用代码；公开页面不展示测试过程，也不保证其他账户、地区、输入或未来服务状态相同。读者应按照[复现步骤](验证与复现.md)验证自己的环境。修改过的参数、提示词、工具或媒体不自动继承原例结果。

## 官方事实与项目约定

型号身份、接口、参数、价格和生命周期在相关段落或表格行链接官方页面。项目默认值、安全习惯和排查顺序明确标为项目建议或项目规则。未确认的能力写成未知，不把缺示例、限流或未公开记录当成不支持。

价格直接跳转官方入口：[DeepSeek](https://api-docs.deepseek.com/quick_start/pricing/)、[Kimi](https://platform.kimi.com/docs/pricing/chat)、[智谱 GLM](https://docs.bigmodel.cn/cn/guide/start/pricing)、[通义千问](https://help.aliyun.com/zh/model-studio/model-pricing)、[豆包方舟](https://docs.volcengine.com/docs/ark/model-pricing?lang=zh)、[MiniMax](https://platform.minimax.cn/docs/guides/pricing-paygo)。

## 付费型号选型（项目规则）

厂商默认型号、维护示例和默认生成代码全部使用付费型号；不为省钱选择免费型号，不在失败后静默回退。型号卡的 `billing.type` 引用官方定价；赠送额度不改变按量计费性质，`Flash` 名称也不等于免费。用户明确指定其他型号时按准确 ID 核对，不擅自改名。

## 三个入口与事实维护

[人类篇](../human/README.md)负责学习和人工核对，[模型目录](../models/README.md)按厂商/型号集中说明书、参数及代码，[Agent 篇](../agents/README.md)提供接入、迁移与排错流程。Agent 的规范入口是 [SKILL.md](../skills/model-manual/SKILL.md)。

准确型号的官方事实维护在[型号卡片](../skills/model-manual/references/models/)，[厂商目录](../skills/model-manual/references/vendors.json)只负责路由和默认型号。发现层的[语言模型清单](model-lists/README.md)按官方资料维护生命周期、模态和价格入口，已下线型号不列出；别名或同系列不继承仓库覆盖。

官方改写示例标为 `adapted_from_official`，其 `examples/sources.json` 保留官方出处、资料核对日期、必需环境变量、运行命令及项目改写。公开的 `verification.live=private` 表示实测记录不发布，不等于 `not_run`，也不是读者可审计的通过证明。型号卡 `verification=null` 与 `verification_scope=private` 同样只表达发布边界；`not_run` 表示该类统一流程没有记录。公开能力摘要只从官方依据生成 `documented` 或 `unknown`，不靠私有记录宣称 `verified`。

[官方示例索引](官方示例索引.md)、[调用代码目录](示例实测状态.md)和[人类完整代码阅读页](../human/examples/README.md)只展示调用代码、用途与出处，不链接私有报告。阅读页逐字复制规范源码，不建立第二套可执行示例，也不声称页面本身被执行过。完整结束、JSON 解析与工具闭环等检查仍保留在代码中。

## 本地验证与实测时间最小化（项目规则）

本地报告默认写入被 Git 忽略的 `.local/evidence/`；源码指纹只用于维护时识别变更，不对外展示。新报告不保存执行日期、时间戳或耗时，不保存 Key、消息/回复/思考正文、原始错误或请求 ID。超时、有限重试和结果完整性检查仍正常使用。修改源码或依赖后，不改旧报告哈希冒充复测；没有本地证据时明确说明，而非补成通过。

普通接入与离线检查不授权真实模型调用；只有用户明确要求后才执行可能计费、上传输入的测试。操作方式见[验证与复现](验证与复现.md)。本地记录移出当前公开树，不表示已经清除过去公开的 Git 历史；不自动重写历史或强制推送。官方资料核对与模型生命周期日期保留，它们不是测试日期。

## 双语维护（项目规则）

中英文共用官方卡片与调用代码，不建立英文报告，也不因翻译重新调用模型。[翻译清单](../en/translations.json)的源文件哈希只用于译文复核，不是实测指纹；先核对英文，再更新已复核哈希。生成与检查命令见[验证与复现](验证与复现.md)。

本仓库要求 Python 3.10+，使用[锁定依赖](../requirements-lock.txt)。离线 mock 只证明模拟边界，不证明真实服务接受请求或业务结果正确；工具天气、订单和库存均为教学模拟，不是实时业务系统。
