# 01 · 5 分钟跑通第一次调用

本章用 DeepSeek 官方提供的 OpenAI-compatible 接口完成第一次文本调用；模型名、地址与参数以[官方文档](https://api-docs.deepseek.com/)为准。

## 1. 准备 Python

本仓库示例要求 Python 3.9 或更高版本，这是仓库自身的运行约定；Python 安装包来自 [python.org](https://www.python.org/downloads/)。

```bash
python3 --version
pip3 install -r requirements.txt
```

`requirements.txt` 声明了示例使用的 OpenAI Python SDK 版本范围；SDK 的安装与 `OpenAI` 客户端用法也可查 [OpenAI 官方仓库](https://github.com/openai/openai-python)。

## 2. 创建 Key

在 [DeepSeek API Keys](https://platform.deepseek.com/api_keys) 创建 Key；DeepSeek 的余额、计费方式和当前价格以[官方价格页](https://api-docs.deepseek.com/quick_start/pricing/)为准。

本项目规则是不把 Key 写进代码或提交到 Git；示例只读取环境变量。[项目核验与安全规则](来源与核验规则.md)

```bash
# macOS / Linux
export DEEPSEEK_API_KEY="你的Key"
```

```powershell
# Windows PowerShell
$env:DEEPSEEK_API_KEY="你的Key"
```

## 3. 运行最小示例

DeepSeek 官方当前给出的接口地址是 `https://api.deepseek.com`，推荐入口是 `deepseek-flash`。[官方接口与模型页](https://api-docs.deepseek.com/quick_start/pricing/)

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["DEEPSEEK_API_KEY"],
    base_url="https://api.deepseek.com",
)

response = client.chat.completions.create(
    model="deepseek-flash",
    messages=[{"role": "user", "content": "用一句话介绍你自己"}],
)
print(response.choices[0].message.content)
print(response.usage)
```

同一示例保存在 [`examples/01_quickstart.py`](../examples/01_quickstart.py)；运行方式由该文件和仓库依赖共同定义。

```bash
python3 examples/01_quickstart.py
```

`messages`、`choices[0].message.content` 与 `usage` 的字段结构可在 DeepSeek 的[聊天接口文档](https://api-docs.deepseek.com/api/create-chat-completion/)中核对。

如果请求失败，先保留完整状态码和错误文本，再按 [05 报错速查](05-新手必会与报错速查.md)处理；本项目不会把未经官方文档或复现支持的原因写成确定结论。[核验规则](来源与核验规则.md)
