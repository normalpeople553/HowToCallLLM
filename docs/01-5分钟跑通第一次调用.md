# 01 · 5 分钟跑通第一次调用

这一章的目标只有一个：**让模型在你的终端里回你一句话。** 不用懂任何术语，照着做就行。

我们用 DeepSeek 做演示，原因：便宜、注册快、对新手友好。（想完全不花钱可以改用智谱的免费模型，做法一模一样，见[智谱攻略](03-厂商攻略/zhipu.md)。）

---

## 第 1 步：装 Python（已有可跳过）

打开终端（macOS 叫"终端"，Windows 叫"PowerShell"），输入：

```bash
python3 --version
```

能打印出 `Python 3.9` 或更高版本就行。没有的话，去 [python.org](https://www.python.org/downloads/) 下载安装，一路下一步。

## 第 2 步：装 openai 这个库

注意，我们装的是 OpenAI 官方的 Python 库，但**用它来调国产模型**——这是后面[第 02 章](02-一个套路调遍所有模型.md)的核心，先照做：

```bash
pip3 install openai
```

## 第 3 步：注册并领取 API Key 📄

1. 打开 DeepSeek 开放平台：<https://platform.deepseek.com/>
2. 用手机号注册登录；
3. 左侧菜单找到「API keys」（接口密钥），点「创建」，复制那串以 `sk-` 开头的字符。

> ⚠️ **这串字符就是钱。** 它等同于你账户的密码，任何人拿到都能用你的余额。**绝对不要**把它发到群里、贴到截图里、提交到 GitHub。下一章我们会用"环境变量"把它藏好。

4. DeepSeek 账户有「赠送余额」一说：📄 官方扣费规则是**优先扣减赠送余额**（[模型与价格页](https://api-docs.deepseek.com/zh-cn/quick_start/pricing)），是否有赠送以控制台显示为准。没有的话，在「充值」里充 **1 块钱**就够你调试很久了（一次问答通常不到 1 分钱）。

## 第 4 步：把 Key 存进环境变量

不要把 key 写死在代码里。在终端里临时设置（关掉终端就失效，适合第一次测试）：

```bash
# macOS / Linux
export DEEPSEEK_API_KEY="sk-这里换成你刚才复制的key"
```

```powershell
# Windows PowerShell
$env:DEEPSEEK_API_KEY="sk-这里换成你刚才复制的key"
```

> 想永久生效的配置方法见 [05 章 · 附录](05-新手必会与报错速查.md#附录把-api-key-永久配置好)。

## 第 5 步：写 7 行代码

新建一个文件 `hello.py`，内容如下（也可以直接用 [`../examples/01_quickstart.py`](../examples/01_quickstart.py)）：

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["DEEPSEEK_API_KEY"],        # 从环境变量读 key
    base_url="https://api.deepseek.com",           # DeepSeek 的"门店地址"
)

resp = client.chat.completions.create(
    model="deepseek-v4-flash",                     # 用哪个模型
    messages=[{"role": "user", "content": "用一句话介绍你自己"}],
)
print(resp.choices[0].message.content)
```

运行：

```bash
python3 hello.py
```

如果终端打印出了一句模型的自我介绍——🎉 恭喜，你已经会调用大模型了。

## 刚才发生了什么？（大白话版）

用「去餐厅吃饭」打个比方，你刚才发出去的是一份点餐请求：

| 代码里的东西 | 餐厅比喻 | 说明 |
|---|---|---|
| `api_key` | 你的会员卡/付款码 | 证明"是我"，费用从这个账户扣 |
| `base_url` | 餐厅的门店地址 | 请求该发给哪台服务器 |
| `model` | 菜名 | 你要用哪个模型（DeepSeek 有好几个） |
| `messages` | 你点的菜 / 说的话 | 你想问模型的内容 |
| 返回的 `resp` | 服务员端上来的菜 | 模型生成的回答 |

其中 `messages` 是一个列表，里面每条消息长这样：

```python
{"role": "user", "content": "你好"}
```

- `role`（角色）：`user` 代表"用户说的"，`assistant` 代表"模型说的"，`system` 代表"给模型定的规矩"；
- `content`（内容）：具体文字。

现在不用记，下一章会把这套东西彻底讲透。

## 顺手看看花了多少钱

把最后一行改成下面这样，能看到这次调用消耗的 token：

```python
print(resp.choices[0].message.content)
print(resp.usage)        # 这次用了多少 token
```

你会看到类似 `prompt_tokens=12, completion_tokens=20` 的输出。对照 [DeepSeek 价格](04-免费额度与省钱攻略.md)算一算——大概率是**几厘钱**。这也是新手最该建立的直觉：**大模型 API 远比你想的便宜。**

## 如果报错了

别慌，99% 的新手错误都集中在这几个，直接去 [05 章 · 报错速查](05-新手必会与报错速查.md) 对号入座：

- `401 Authentication Fails` → key 错了 / 没读到环境变量；
- `402 Insufficient Balance` → 账户没余额 / 没用上赠送额度；
- `model not found` / `Model Not Exist` → 模型名写错或过期；
- 连接超时、`Connection error` → 网络问题（国内调用这五家通常无需代理，开了代理反而可能出错）。
