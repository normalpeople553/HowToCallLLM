# 02 · 一个套路调遍所有模型

五家厂商都在官方文档中提供 OpenAI-compatible Chat Completions 用法：[DeepSeek](https://api-docs.deepseek.com/)、[Kimi](https://platform.kimi.com/docs/api/chat)、[智谱](https://docs.bigmodel.cn/cn/guide/develop/openai/introduction)、[通义](https://help.aliyun.com/zh/model-studio/qwen-api-via-openai-chat-completions/)、[豆包](https://docs.volcengine.com/docs/ark/online-inference-standard?lang=zh)。“compatible”只描述这里使用的聊天接口，不表示所有 OpenAI API 都兼容。[项目边界](../skills/model-manual/SKILL.md)

## 通用模板

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["API_KEY"],
    base_url="厂商接口地址",
)

response = client.chat.completions.create(
    model="厂商模型名",
    messages=[{"role": "user", "content": "你好"}],
)
print(response.choices[0].message.content)
```

这段模板的字段来自 OpenAI Python SDK 的 [Chat Completions 示例](https://github.com/openai/openai-python)；各厂商可变值来自下列官方文档。

| 厂商 | `base_url` | 模型 | 专属参数来源 |
|---|---|---|---|
| DeepSeek | [`https://api.deepseek.com`](https://api-docs.deepseek.com/) | [`deepseek-flash`](https://api-docs.deepseek.com/quick_start/pricing/) | [思考模式](https://api-docs.deepseek.com/guides/thinking_mode/) |
| Kimi | [`https://api.moonshot.cn/v1`](https://platform.kimi.com/docs/get-api-key) | [`kimi-k2.6`](https://platform.kimi.com/docs/models) | [思考模式](https://platform.kimi.com/docs/guide/use-thinking-models) |

## 对话、流式与思考

多轮对话需要把历史 `messages` 随下一次请求再次传入；`system`、`user`、`assistant` 角色定义可查各家的聊天接口，例如 [Kimi Chat API](https://platform.kimi.com/docs/api/chat)。仓库的完整示例见 [`examples/04_multi_turn.py`](../examples/04_multi_turn.py)。

流式输出由 `stream=True` 开启；Kimi 的官方说明和数据事件格式见[流式输出指南](https://platform.kimi.com/docs/guide/utilize-the-streaming-output-feature-of-kimi-api)，仓库示例见 [`examples/03_streaming.py`](../examples/03_streaming.py)。

```python
stream = client.chat.completions.create(
    model="deepseek-flash",
    messages=[{"role": "user", "content": "讲个短故事"}],
    stream=True,
)
for chunk in stream:
    print(chunk.choices[0].delta.content or "", end="", flush=True)
```

思考开关不是统一标准：DeepSeek 与 Kimi 的官方写法是 `thinking.type`，[DeepSeek 来源](https://api-docs.deepseek.com/guides/thinking_mode/) · [Kimi 来源](https://platform.kimi.com/docs/guide/use-thinking-models/)；通义 Python SDK 使用 `extra_body={"enable_thinking": False}`，[通义来源](https://help.aliyun.com/zh/model-studio/qwen-api-via-openai-chat-completions/)。智谱 `glm-4.7-flash` 与豆包当前条目的关闭写法由仓库在 2026-10-13 通过 [`tests/verify_calls.py`](../tests/verify_calls.py)验证；不要把该结果外推到其他代际，GLM-5.3 官方明确有不同限制。[GLM-5.3 文档](https://docs.bigmodel.cn/cn/guide/models/vlm/glm-5.3-flash)

```python
# DeepSeek / Kimi；智谱与豆包仅限目录中已验证模型
extra_body={"thinking": {"type": "disabled"}}

# 通义
extra_body={"enable_thinking": False}
```
