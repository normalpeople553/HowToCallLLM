## 通用模板

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["API_KEY"],
    base_url="厂商接口地址",
)

response = client.chat.completions.create(
    model="厂商模型名",
    messages=[{"role": "user", "content": "你好"}],
)
print(response.choices[0].message.content)
```

这段模板的字段来自 OpenAI Python SDK 的 [Chat Completions 示例](https://github.com/openai/openai-python)；各厂商可变值来自下列官方文档。

## 对话、流式与思考

多轮对话需要把历史 `messages` 随下一次请求再次传入；`system`、`user`、`assistant` 角色定义可查各家的聊天接口，例如 [Kimi Chat API](https://platform.kimi.com/docs/api/chat)。仓库的完整示例见 [`examples/04_multi_turn.py`](../examples/04_multi_turn.py)。

流式输出由 `stream=True` 开启；Kimi 的官方说明和数据事件格式见[流式输出指南](https://platform.kimi.com/docs/guide/utilize-the-streaming-output-feature-of-kimi-api)，仓库示例见 [`examples/03_streaming.py`](../examples/03_streaming.py)。

```python
stream = client.chat.completions.create(
    model="deepseek-flash",
    messages=[{"role": "user", "content": "讲个短故事"}],
    stream=True,
)
for chunk in stream:
    if not chunk.choices:
        continue
    print(chunk.choices[0].delta.content or "", end="", flush=True)
```

思考开关不是统一标准：DeepSeek 与 Kimi 的官方写法是 `thinking.type`，[DeepSeek 来源](https://api-docs.deepseek.com/guides/thinking_mode/) · [Kimi 来源](https://platform.kimi.com/docs/guide/use-thinking-models/)；通义 Python SDK 使用 `extra_body={"enable_thinking": False}`，[通义来源](https://help.aliyun.com/zh/model-studio/qwen-api-via-openai-chat-completions/)。智谱 GLM-4.7 与豆包的思考行为分别见[智谱思考模式](https://docs.bigmodel.cn/cn/guide/capabilities/thinking-mode)和[方舟深度思考](https://docs.volcengine.com/docs/ark/deep-thinking?lang=zh)。2026-10-13 智谱历史验证记录为限流，具体运行结果统一查[验证状态](验证状态.md)。不要把 GLM-4.7 的关闭方式外推到 GLM-5.3。[GLM-5.3 文档](https://docs.bigmodel.cn/cn/guide/models/vlm/glm-5.3-flash)

```python
# DeepSeek / Kimi；智谱与豆包按具体型号官方说明
extra_body={"thinking": {"type": "disabled"}}

# 通义
extra_body={"enable_thinking": False}
```

MiniMax M2.7 不使用上面的关闭示例：其 `thinking.type=disabled` 被接收但不生效，`reasoning_split=true` 仅把思考与正文拆开；生成器会拒绝该型号的 `--thinking off`。原生 `/text/chatcompletion_v2` 也不是 OpenAI SDK 的 Base URL，区别见[M2.7 说明书](../models/minimax/MiniMax-M2.7/README.md)。[MiniMax 官方规则](https://platform.minimax.cn/docs/api-reference/text-chat-openai)

需要直接生成型号版本时，运行 [`skills/model-manual/scripts/generate_snippet.py`](../skills/model-manual/scripts/generate_snippet.py)；它读取厂商目录和[模型卡片](../skills/model-manual/references/models/)，检查型号归属、能力、思考开关和输出预算。生成器使用方法见[README](../README.md#让说明书生成代码)。流式完整示例还会跟踪结束原因和用量；不要仅用上述正文打印片段判断请求成功。[真实踩雷](06-真实踩雷与生产检查.md)
