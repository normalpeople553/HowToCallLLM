## 模型怎么开通

本页的语言模型与独立 STT/TTS 分属**方舟**和**豆包语音**两套服务；各自在目标项目中开通模型、创建 API Key。已有 `ARK_API_KEY` 不等于已开通豆包语音，也不要拿它当语音接口的 `X-Api-Key`。[方舟 API Key](https://docs.volcengine.com/docs/ark/api-key?lang=zh) · [豆包语音控制台指引](https://docs.volcengine.com/docs/DoubaoVoice/console-guidance?lang=zh)

### 本页语言模型：火山方舟

1. 登录[方舟开通管理](https://docs.volcengine.com/docs/ark/activation-management?lang=zh)，切到准备用来调用的项目，找到目标**准确 Model ID**，点击「开通服务」并按弹窗提示确认。若显示「邀测中」，官方说明不能自助开通，需要提交工单；是否可用以控制台状态为准。[开通管理](https://docs.volcengine.com/docs/ark/activation-management?lang=zh)
2. 如果勾选「自动开通新增模型」，也仍需单独手动开通 `doubao-seed-evolving`。开通后检查状态与计费信息；不要把免费额度或“已开通”理解为永久免费。[开通管理](https://docs.volcengine.com/docs/ark/activation-management?lang=zh)
3. 在同一项目的[方舟 API Key 管理](https://docs.volcengine.com/docs/ark/api-key?lang=zh)创建/获取 Key，按下文设置为 `ARK_API_KEY`。如果 Key 被限定 Model ID 或 IP，也要确认当前调用在授权范围内。[方舟 API Key](https://docs.volcengine.com/docs/ark/api-key?lang=zh)

### 独立 STT/TTS：豆包语音

这里的 STT 指音频转文字，TTS 指文字转音频。它们**不在上方舟型号表内**，但语音合成 2.0 和流式语音识别 2.0 已有[实际跑通的独立示例](../models/doubao/voice/README.md)。以下是官方开通路径。[豆包语音控制台指引](https://docs.volcengine.com/docs/DoubaoVoice/console-guidance?lang=zh)

1. 进入[豆包语音新版控制台指引](https://docs.volcengine.com/docs/DoubaoVoice/QuickStartNewConsole?lang=zh)所示的控制台，先确认左上角的目标项目。首次使用的新用户按官方指引完成注册与实名认证；是否有一键开通入口，以控制台实际展示为准。[新版控制台快速入门](https://docs.volcengine.com/docs/DoubaoVoice/QuickStartNewConsole?lang=zh)
2. 左侧进入「开通管理」，按用途分别找到并开通对应模型：要做 STT，选择所需的**录音文件识别**或**流式语音识别**能力；要做 TTS，选择**豆包语音合成模型 2.0**。点击「开通」、阅读并勾选协议，再点击「开通模型」。**开通一种语音模型不代表其他语音模型也已开通**；以同项目的服务状态为准。[控制台指引](https://docs.volcengine.com/docs/DoubaoVoice/console-guidance?lang=zh) · [新版控制台快速入门](https://docs.volcengine.com/docs/DoubaoVoice/QuickStartNewConsole?lang=zh)
3. 在同一项目的「API管理」/「API Key管理」创建或获取**豆包语音 API Key**。接口请求使用 `X-Api-Key`，并带上与所开通能力匹配的 `X-Api-Resource-Id`；不要用方舟的 `ARK_API_KEY` 替代。项目不同，Key 和模型资源也不共享。[控制台指引](https://docs.volcengine.com/docs/DoubaoVoice/console-guidance?lang=zh) · [录音文件识别极速版 HTTP](https://docs.volcengine.com/docs/DoubaoVoice/recording-file-recognition-lite-http?lang=zh) · [TTS HTTP](https://docs.volcengine.com/docs/DoubaoVoice/unidirectional-streaming-text-to-speech-http?lang=zh)
4. 对照所选接口的官方文档检查资源 ID：例如[录音文件识别 2.0 标准版](https://docs.volcengine.com/docs/DoubaoVoice/LargemodelrecordingfilerecognitionstandardversionAPI?lang=zh)使用 `volc.seedasr.auc`，[语音合成 2.0](https://docs.volcengine.com/docs/DoubaoVoice/unidirectional-streaming-text-to-speech-http?lang=zh)使用 `seed-tts-2.0`。TTS 还要从[官方音色库](https://docs.volcengine.com/docs/DoubaoVoice/console-guidance?lang=zh)取得与模型匹配的 Speaker ID。[录音文件识别极速版](https://docs.volcengine.com/docs/DoubaoVoice/recording-file-recognition-lite-http?lang=zh)则是另一个接口，示例资源 ID 为 `volc.bigasr.auc_turbo`；不要与标准版或流式接口混用。

开通前可在[豆包语音控制台指引](https://docs.volcengine.com/docs/DoubaoVoice/console-guidance?lang=zh)查看计费与资源购买入口；实际价格、余额、免费额度及服务状态以**自己项目的控制台**为准。若看不到「开通管理」，子账号可能缺少语音技术系统权限，参见[控制台 FAQ](https://docs.volcengine.com/docs/DoubaoVoice/ConsoleUsageFAQ?lang=zh)。

### 已开通语音能力的调用对照

以下是根据用户提供的豆包语音控制台截图与官方接口文档整理的**接入路线**。其中 TTS 2.0 与流式 STT 2.0 已通过[仓库中的真实调用代码](../models/doubao/voice/README.md)验证；另外三项仅有官方路线，不能视作本仓库已跑通。选用前仍须核对同项目的服务状态、语音 API Key、音色及计费方式。[控制台指引](https://docs.volcengine.com/docs/DoubaoVoice/console-guidance?lang=zh)

| 控制台能力 | 官方接口与必要标识 | 关键流程 |
|---|---|---|
| 语音合成 2.0（TTS）✅实测 | [单向流式 TTS HTTP](https://docs.volcengine.com/docs/DoubaoVoice/unidirectional-streaming-text-to-speech-http?lang=zh)；`X-Api-Resource-Id: seed-tts-2.0` | [运行代码](../models/doubao/voice/tts_2_0.py)：发送 `text`、兼容的 `speaker` 和 `audio_params`，拼接音频分片到本地 MP3。音色 ID 可从[音色库](https://docs.volcengine.com/docs/DoubaoVoice/console-guidance?lang=zh)复制。 |
| 录音文件识别 2.0（STT） | [标准版 HTTP](https://docs.volcengine.com/docs/DoubaoVoice/LargemodelrecordingfilerecognitionstandardversionAPI?lang=zh)；`X-Api-Resource-Id: volc.seedasr.auc` | 提交可访问的音频 URL 获取任务 ID，再用[结果查询接口](https://docs.volcengine.com/docs/DoubaoVoice/result-query-http-1?lang=zh)轮询；不是一次请求就直接得到最终文字。 |
| 流式语音识别 2.0（STT）✅实测小时版 | [一句话识别 WebSocket](https://docs.volcengine.com/docs/DoubaoVoice/unidirectional-streaming-automatic-speech-recognition-websocket?lang=zh)；时长版 `volc.seedasr.sauc.duration`，并发版 `volc.seedasr.sauc.concurrent` | [运行代码](../models/doubao/voice/streaming_asr_2_0.py)：MP3 转 WAV，按官方二进制协议分包发送，收到非空识别文字；并发版未实测。 |
| 声音复刻 2.0 | [声音复刻 V3 训练接口](https://docs.volcengine.com/docs/DoubaoVoice/SoundReplicaAPI-V3?lang=zh)；生成语音时见[TTS 的 `seed-icl-2.0` 资源 ID](https://docs.volcengine.com/docs/DoubaoVoice/unidirectional-streaming-text-to-speech-http?lang=zh) | 先取得合法可用的复刻音色 ID、按 V3 接口训练并检查状态，之后才用该音色合成。若控制台显示音色槽位未开通，还要按[官方订购指引](https://docs.volcengine.com/docs/DoubaoVoice/Soundreplicationorderingandusageguide?lang=zh)选择预付费槽位或另行开通后付费音色服务；仅开通复刻模型不足以完成复刻调用。 |
| 音频生成 1.0 | 官方[通过 AI MediaKit 调用音频生成大模型](https://docs.volcengine.com/docs/Intelligentprocessing/audio-generation?lang=zh)示例使用 `model: seed-audio-1.0` | 这是由提示词生成音频场景的能力，**不是**上面的 TTS 2.0。该官方接入路线还要求跨服务授权与单独的 MediaKit API Key，提交异步任务后查询结果；不能直接套用语音合成接口。 |

本页仅发布已用豆包语音专用 Key 跑通的[TTS 和流式 STT 代码](../models/doubao/voice/README.md)，不把控制台“已开通”当作其余三项 API 调用成功的证据。[验证规则](来源与核验规则.md)

## 直接运行

先按照[官方 API Key 指南](https://docs.volcengine.com/docs/ark/api-key?lang=zh)设置 `ARK_API_KEY` 环境变量，并安装 `openai` Python 包。然后在仓库根目录运行：

```bash
python models/doubao/verified_calls.py --model doubao-seed-2-1-pro-260915
python models/doubao/verified_calls.py --model doubao-seed-translation-250915
```

把 `--model` 换成上表任一准确 ID；文件会拒绝未列入的型号。源码：[verified_calls.py](../models/doubao/verified_calls.py)。方舟的 Chat 与 Responses 入口、`model` 字段见[Chat API](https://docs.volcengine.com/docs/ark/chat-api?lang=zh)和[Responses API](https://docs.volcengine.com/docs/ark/create-model-responses-api?lang=zh)。

## 验证边界

本页“已验证”仅指这个文件的最小文本/翻译请求执行成功，并检查了完成状态和非空正文；不代表回答质量、全部能力、吞吐或生产稳定性。图片、音频理解、视频、流式、工具和结构化输出的探索性调用不自动成为本文件的逐型号示例；独立 STT/TTS 属于[豆包语音服务](https://docs.volcengine.com/docs/DoubaoVoice/console-guidance?lang=zh)，不由方舟文本 Model ID 或本文件覆盖。[验证规则](来源与核验规则.md)
