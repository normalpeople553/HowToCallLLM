## 直接运行

先按照[官方 API Key 指南](https://docs.volcengine.com/docs/ark/api-key?lang=zh)设置 `ARK_API_KEY` 环境变量，并安装 `openai` Python 包。然后在仓库根目录运行：

```bash
python models/doubao/verified_calls.py --model doubao-seed-2-1-pro-260915
python models/doubao/verified_calls.py --model doubao-seed-translation-250915
```

把 `--model` 换成上表任一准确 ID；文件会拒绝未列入的型号。源码：[verified_calls.py](../models/doubao/verified_calls.py)。方舟的 Chat 与 Responses 入口、`model` 字段见[Chat API](https://docs.volcengine.com/docs/ark/chat-api?lang=zh)和[Responses API](https://docs.volcengine.com/docs/ark/create-model-responses-api?lang=zh)。

## 看懂实际发送的参数

| 字段 | 这份代码的含义 | 出处 |
|---|---|---|
| `model` | 选择一个**准确 ID**，不是系列名；代码不自动回退到其他型号 | [模型列表](https://docs.volcengine.com/docs/ark/model-list?lang=zh) · [源码](../models/doubao/verified_calls.py) |
| `messages` | 普通型号的 Chat API 输入；本例只发一条 `user` 文本 | [Chat API](https://docs.volcengine.com/docs/ark/chat-api?lang=zh) · [源码](../models/doubao/verified_calls.py) |
| `thinking.type="disabled"` | 对支持思考的 Chat 型号关闭思考，不是温度或上下文长度开关；不支持该能力的 `character-251128` 不发送此字段 | [深度思考](https://docs.volcengine.com/docs/ark/deep-thinking?lang=zh) · [模型列表](https://docs.volcengine.com/docs/ark/model-list?lang=zh) |
| `input[].content[].translation_options` | 翻译型号在 Responses API 中指定源语言 `zh`、目标语言 `en`；不可把翻译型号直接套入 Chat 请求 | [Responses API](https://docs.volcengine.com/docs/ark/create-model-responses-api?lang=zh) · [源码](../models/doubao/verified_calls.py) |
| `timeout=120`、`max_retries=0` | 客户端等待上限和重试设置；不是模型上下文、输出预算或采样参数 | [源码](../models/doubao/verified_calls.py) · [OpenAI Python SDK](https://github.com/openai/openai-python#timeouts) |

本文件**没有**设置 `temperature`、`top_p`、`max_tokens` 或 `max_completion_tokens`，所以不能把这些参数说成已经逐型号实测。[源码](../models/doubao/verified_calls.py) · [Chat API 参数](https://docs.volcengine.com/docs/ark/chat-api?lang=zh)

## 验证边界

本页“已验证”仅指这个文件的最小文本/翻译请求执行成功，并检查了完成状态和非空正文；不代表回答质量、全部能力、吞吐或生产稳定性。图片、音频理解、视频、流式、工具和结构化输出的探索性调用不自动成为本文件的逐型号示例；独立 STT/TTS 属于[豆包语音服务](https://docs.volcengine.com/docs/DoubaoVoice/console-guidance?lang=zh)，不由方舟文本 Model ID 或本文件覆盖。[验证规则](来源与核验规则.md)

`doubao-seed-2-0-pro-260215` 和 `doubao-seed-2-0-mini-260215` 仍可在[官方列表](https://docs.volcengine.com/docs/ark/model-list?lang=zh)查到，但这轮未能用当前账号跑通，因此**没有**加入上表或可选代码。404 `InvalidEndpointOrModel.NotFound` 既可能表示不存在，也可能表示当前账号无权访问，不能据此写成“已下线”。[官方错误码](https://docs.volcengine.com/docs/ark/error-codes?lang=zh)
