# 豆包：逐模型开通入口与 API Key 对照

[English](../en/docs/doubao-access-and-keys.md) · [已验证调用](豆包已验证调用.md) · [语言模型清单](model-lists/doubao.md)

先选**服务**，再选模型：火山方舟、豆包语音和 AI MediaKit 的 Key 不是同一类。下表的链接指向官方控制台页面；需要登录，且语音链接中的 `projectName=default` 指默认项目，使用其他项目时应在控制台切换。**拿到 Key 不等于已开通所有模型**：还要看目标项目、模型开通状态、计费资源，以及 Key 自身的 Model ID / IP 限制。[方舟开通管理](https://docs.volcengine.com/docs/ark/activation-management?lang=zh) · [方舟 API Key](https://docs.volcengine.com/docs/ark/api-key?lang=zh) · [豆包语音控制台指引](https://docs.volcengine.com/docs/DoubaoVoice/console-guidance?lang=zh)

## 豆包语音模型：共用同项目语音 Key

在[豆包语音开通管理][voice-open]选中下面的**具体能力**，然后到[豆包语音 API Key 管理][voice-key]获取同一项目的 Key，代码中保存为 `DOUBAO_VOICE_API_KEY`，接口一般放在 `X-Api-Key` 请求头。**一把语音 Key 可以用于该项目已开通、接口兼容的多个语音模型**；仅开通某一项，不会自动开通其余项。音色 ID、模型 ID、资源 ID 也不是 API Key。[官方控制台指引](https://docs.volcengine.com/docs/DoubaoVoice/console-guidance?lang=zh) · [API Key 用法](https://docs.volcengine.com/docs/DoubaoVoice/APIKeyUsage?lang=zh)

| 控制台模型 / 能力 | 开通入口 | 获取 Key | 请求时还要选什么 | 本仓库验证 |
|---|---|---|---|---|
| 语音合成 2.0 | [语音开通][voice-open] | [语音 Key][voice-key] | `X-Api-Resource-Id: seed-tts-2.0`；兼容的音色 ID。[官方接口](https://docs.volcengine.com/docs/DoubaoVoice/unidirectional-streaming-text-to-speech-http?lang=zh) | [已跑通](../models/doubao/voice/tts_2_0.py) |
| 流式语音识别 2.0 | [语音开通][voice-open] | [语音 Key][voice-key] | 小时版 `volc.seedasr.sauc.duration` 或并发版 `volc.seedasr.sauc.concurrent`；本仓库只测过小时版。[官方接口](https://docs.volcengine.com/docs/DoubaoVoice/unidirectional-streaming-automatic-speech-recognition-websocket?lang=zh) | [小时版已跑通](../models/doubao/voice/streaming_asr_2_0.py) |
| 录音文件识别 2.0 | [语音开通][voice-open] | [语音 Key][voice-key] | 标准版 `volc.seedasr.auc`，并提供服务端可访问的音频 URL。[官方接口](https://docs.volcengine.com/docs/DoubaoVoice/LargemodelrecordingfilerecognitionstandardversionAPI?lang=zh) | [标准版已跑通](../models/doubao/voice/recorded_asr_2_0.py) |
| 音频生成 1.0 | [语音开通][voice-open] | [语音 Key][voice-key] | 直连接口传 `model: seed-audio-1.0`，**不是** `X-Api-Resource-Id`；返回音频和临时 URL。[官方接口](https://docs.volcengine.com/docs/DoubaoVoice/audio-generation-http?lang=zh) | [直连接口已跑通](../models/doubao/voice/audio_generation_1_0.py) |
| 声音复刻 2.0 | [语音开通][voice-open] | [语音 Key][voice-key] | 训练需有权使用的样音、可用音色 ID/槽位或后付费音色服务；复刻音色合成用 `seed-icl-2.0`。[训练接口](https://docs.volcengine.com/docs/DoubaoVoice/SoundReplicaAPI-V3?lang=zh) · [音色订购](https://docs.volcengine.com/docs/DoubaoVoice/Soundreplicationorderingandusageguide?lang=zh) | 尚未实测，不宣称可调用 |

这里的开通链接进入项目列表，不保证直接定位到某一行；打开后按模型中文名查找。若打不开或看不到「开通管理」，检查登录、项目和子账号权限。[新版控制台步骤](https://docs.volcengine.com/docs/DoubaoVoice/QuickStartNewConsole?lang=zh) · [控制台 FAQ](https://docs.volcengine.com/docs/DoubaoVoice/ConsoleUsageFAQ?lang=zh)

## 同一个「音频生成 1.0」还有 MediaKit 代理路线

通过[豆包语音直连接口](https://docs.volcengine.com/docs/DoubaoVoice/audio-generation-http?lang=zh)用**豆包语音 Key**即可请求已开通的 `seed-audio-1.0`；这是本仓库已实测的路线。若改用[AI MediaKit 代理接入](https://docs.volcengine.com/docs/Intelligentprocessing/audio-generation?lang=zh)，则还须到[MediaKit 授权管理][mediakit-auth]做跨服务授权，并在[MediaKit API Key 管理][mediakit-key]创建**MediaKit Key**。在这条路线里，MediaKit Key 用于代理接口鉴权，不能代替语音直连接口的 Key 或方舟 Key。先前拿语音 Key 请求 MediaKit 代理接口返回 403，不能推断语音直连接口不可用。[MediaKit 官方指南](https://docs.volcengine.com/docs/Intelligentprocessing/audio-generation?lang=zh)
