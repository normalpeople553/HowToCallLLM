## 2. 一次调用到底多便宜？建立直觉

不用纠结 token 精确定义，先记住量级：**1 个汉字大约占 1～2 个 token**。

- 一段 500 字的提问 ≈ 几百到 1000 输入 token；
- 模型回你 500 字 ≈ 1000 左右输出 token。

拿 `deepseek-v4-flash`（输入 1 元 / 输出 2 元每百万）算：

> 问 1000 token + 答 1000 token ≈ 0.001 + 0.002 = **0.003 元，约 3 厘钱**。

也就是说，**充值 1 块钱，够你来回对话几百次**。大模型 API 对个人学习而言几乎等于不要钱，真正贵的是：一不小心发了超长文本、死循环狂调、或用了顶配模型做小事。

## 5. 七条省钱/防翻车实操

1. **关掉用不到的思考**：新一代模型默认思考，简单问题加 `extra_body` 关思考，实测输出 token 能从几十降到个位数（写法见 [02 章思考对照表](02-一个套路调遍所有模型.md#思考模式五家实测对照2026-10-13-)）。
2. **给输出装保险丝**：调用时设 `max_tokens`（比如 500），模型就算"写嗨了"也有上限。
3. **别用大炮打蚊子**：日常问答用 flash/lite 档，别默认旗舰 max / pro / k3。
4. **按需选模型**：Kimi 已不按上下文长度分价，但 k3 比 k2.6 贵三倍，别拿旗舰做小事。
5. **善用缓存命中价**：DeepSeek 缓存命中输入只要 0.02 元（未命中的 1/50）。反复发送相同的长前缀（如固定的 system 设定、长资料）天然能吃到缓存。
6. **开消费提醒/限额**：各平台控制台都能设余额预警；百炼可开启「[免费额度用完即停](https://help.aliyun.com/zh/model-studio/new-free-quota)」，额度耗尽自动停止，防意外扣费。
7. **先小额试**：第一次充 1～10 元，别上头。调试期用免费模型，正式跑再换付费的。

## 6. 一个重要提醒：价格一定会变

模型每半年迭代一代，价格只降不降是大趋势，但**模型名会下线、计费规则会调整**。本指南所有数字都标了核对日期，真要做长期项目，务必：

- 以官方价格页为准；
- 代码里模型名可用厂商提供的"自动别名"（如 `qwen-flash`），减少因版本下线导致的报错；
- 关注厂商的弃用公告（DeepSeek 就曾在 2026/07 弃用过老模型名）。
