# 00 · 前言

## 为什么会有这份指南

我第一次想在代码里调用大模型时，花了整整一个晚上，结果大部分时间不是在写代码，而是在各家平台里迷路：

- 注册了账号，找不到 API Key 在哪；
- 找到 Key 了，不知道代码里那个 `base_url` 填什么；
- 模型名字千奇百怪：`deepseek-chat`、`moonshot-v1-8k`、`glm-4-flash`、`qwen-turbo`……；
- 最慌的是——**这玩意儿会不会一不小心扣我几百块？**

后来我发现了一个让整件事变简单的事实：**国内这些大模型，调用方式几乎一模一样。** 学会一个套路，剩下的只是"去谁家注册、地址填啥、模型叫啥、多少钱"这种查表的事。

于是就有了这份指南：把我踩过的坑、查过的价格、薅过的免费额度，按新手真正需要的顺序整理出来。

## 这份指南想帮你做到

1. **5 分钟内**，零基础跑通第一次调用，看到模型真的回你一句话；
2. 理解那套"万能模板"，从此看到任何一家国产模型都不发怵；
3. 知道免费额度在哪、怎么选最省钱的第一家；
4. 报错时能在[第 05 章](05-新手必会与报错速查.md)自己救活自己。

## 怎么用这份指南

- **它是备选单，不是任务清单。** 你不需要把四家都试一遍。新手建议：读完 01、02 两章，然后从 [DeepSeek 攻略](03-厂商攻略/deepseek.md)或[智谱免费模型](03-厂商攻略/zhipu.md)里挑一个跑通，就已经入门了。
- **按顺序读 01 → 02，之后随便跳。** 03 厂商篇是字典，用哪家查哪家。
- **代码都在 [`../examples/`](../examples/) 目录**，可以直接复制去跑。

## 几个约定

**关于标记**

| 标记 | 意思 |
|---|---|
| ✅ 已实测 | 作者用真实 key 跑通过 |
| 📄 官方文档 | 来自官方文档，点链接可核实 |
| 💬 社区经验 | 社区/个人经验，仅供参考 |
| ⚠️ 易变 | 价格、模型名、免费额度会变，用前复核官方链接 |

**关于钱**

- 所有价格单位如果没特别说明，都是 **「元 / 百万 tokens」**。
- 不用慌 token：你可以先粗略理解成"字数"。一次普通问答通常花不到 **1 分钱**，很多模型还有免费额度。详见 [04 省钱攻略](04-免费额度与省钱攻略.md)。
- 本指南强烈建议新手：**先领免费额度 / 只充 1～10 元**，并设置好消费提醒，跑通了再说。

**关于版本**

- 代码默认你用 Python 3.9+，并安装官方 `openai` 库（对，用 OpenAI 的库调国产模型，这是故意的，第 02 章解释为什么）。
- 信息核对日期：**2026-10-13**。大模型迭代极快，模型名和价格以官方文档为准。

## 开始前你只需要准备

1. 一台能装 Python 的电脑（Windows / macOS 都行）；
2. 一个手机号，用来注册模型平台；
3. 10 分钟时间。
